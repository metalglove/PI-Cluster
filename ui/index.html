Circle cover, threshold greedy

Pick k circles that cover as many points as possible. OPT is unknown, so the algorithm tries a ladder of thresholds τ and keeps the best run. Every candidate check is one Spark job, split across the Raspberry Pis.

Algorithm

  1. f(e) ← max single-circle coverage (1 Spark job)
  2. y ← ⌈log k / log(1+ε)⌉
  3. for j = 0 … y:
  4. τ ← (1+ε)j · f(e) / 2k
  5. S ← ∅
  6. while |S| < k:
  7. find any c with Δf(c | S) ≥ τ (1 Spark job)
  8. if found: S ← S ∪ {c}
  9. else: stop this guess
  10. keep S if f(S) is the best so far
  11. return best S
